## Steps to integrate GEE

* Start here https://developers.google.com/earth-engine/earthengine_cloud_project_setup#apply-to-use-earth-engine

* Enable Google Engine API on the project. Go to https://console.developers.google.com/apis/library/earthengine.googleapis.com?project=<YOUR PROJECT ID>
* Ensure you are signed up for Earth Engine. Go to https://earthengine.google.com/signup/
